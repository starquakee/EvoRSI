两轮的估计对象不同：本轮比较的是给定同一初始池后的条件续跑表现，三个池才是独立的起点；上一轮每次搜索各自产生初始草稿。本轮完整设计只需 114 次主请求（6 次建池＋108 次续跑），上一轮为 162 次。起点、总预算和执行时段同时不同，因此这些数值不能证明共享起点导致稳定性改善，也不能证明某配置或外层算法更优。三批次规模较小，结果还条件于固定数据拆分、模型服务和短搜索预算。
