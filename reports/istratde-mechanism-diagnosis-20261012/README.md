# 五个搜索参数的机制诊断

**结论：五个参数都正确接入，主要问题是本轮搜索结构给部分参数的有效作用机会太少，外层反馈又缺乏稳定的区分信号。** 不建议立即扩大原五维实验，也不应据此认定整个内层搜索无效。

本次仅离线读取现有记录，新增模型请求 0、sandbox 作业 0；没有修改参数、重新选择赢家或重算原最终评测。

## 参数究竟有没有控制行为

完整检查 216 次搜索、1,312 条生成操作轨迹和 864 次父代选择。每条轨迹里的交叉概率、成绩/进步/新颖性权重、调试深度都与该次配置一致；根据记录的分量和权重独立复算全部 utility 与 softmax 概率，均在 1e-10 内匹配。

| 参数 | 观察到的实际作用 | 本轮限制 | 后续建议 |
|---|---|---|---|
| crossover_prob | 随配置区间上升，实际交叉占比约为 13.6%、34.8%、53.7%、89.1% | 每次只有 4 个交叉/改进选择机会，单次观测波动很大 | 保留为主要研究维度 |
| score_weight | 622/864 次选择中成绩分量不同，改变权重可改变首个父代的抽样概率 | 验证分数离散且有随机波动，影响概率不等于提高最终准确率 | 保留为主要研究维度 |
| delta_weight | 188/864 次有区分度 | 676 次（78.2%）候选进步分量相同；前一轮选择全部无区分度 | 先固定默认 0.4，待更长搜索再评估 |
| novelty_weight | 128/864 次有区分度 | 736 次（85.2%）候选新颖性相同；Spambase 仅 6/288 次有区分度 | 先固定默认 0.25；之后考虑更有区分度的多样性描述 |
| max_debug_depth | 15/216 次搜索发生调试，共 16 次调试全部成功 | 第二层调试一次也没到达，深度 1 与 2 的额外价值未被检验 | 后续简化试验先固定为 1 |

以上建议是下一份实验协议的候选设计，**当前代码和实验配置未改变，也未证明这些固定值最优**。

交叉概率分箱含样本数分别为 22、56、115、23；中间箱包含固定配置。这里展示参数与行为的一致性，不把这些分箱当成随机对照的性能提升证据。

## 为什么三个权重的有效空间比表面小

父代选择使用：

`utility = score_weight × score_component + delta_weight × delta_component + novelty_weight × novelty_component`

然后计算 softmax。若一个分量对所有候选相同，改变其权重只会给所有 utility 加相同常数，选择概率保持不变。这一点已用真实轨迹逐事件验证。

内层只有三代、每代两个主候选。第 1 代（generation_id=0）只生成草稿；第 2 代（id=1）的 432 次父代选择中，**进步和新颖性分量全部无区分度**；直到最后一代，进步/新颖性才在部分候选池中出现差异。

此外，234/864 次选择会选中整个候选池。此时权重无法改变无序父代集合，但仍可能改变父代排列，从而改变提示顺序，不能把这些事件全部说成“权重毫无影响”。

当前新颖性按粗粒度方法家族计数。轨迹只出现 `ensemble` 和 `sklearn` 两类；这不是程序语义、预测差异或错误互补性的度量。Spambase 的新颖性几乎始终相同，说明这项特征在该任务上很难给优化器提供有用区分。

## 内层搜索仍然产生了改进

比较每次搜索前两个草稿的最佳验证分数与整次搜索最佳分数：

| 任务 | 后续搜索超过初始草稿的次数 |
|---|---:|
| Banknote | 5/72 |
| WDBC | 45/72 |
| Spambase | 49/72 |

445 次 improve 中有 124 次超过其最佳父代；419 次 crossover 中有 71 次超过最佳父代；16 次 debug 均修复为可评分程序。这说明存在实际的内层改进，不能把外层 iStratDE 无增益解释成整个生成/修改/执行流程无用。

但这也不是“进化操作优于同预算纯草稿生成”的因果证明：操作面对的父代不同，而且后续搜索使用了更多候选机会。两个操作的原始成功比例不可直接用来决定删除哪一个。

## 外层为什么没有显示额外增益

- Banknote：72 组配置的最终验证最佳值全部为 1.0，外层评价完全饱和。
- WDBC：72 组配置只有 0.982456 和 0.991228 两个值，61 组达到同一最高值。114 个验证样本使单个样本约对应 0.877 个百分点。
- Spambase：72 组配置有 12 个不同值，但相同初始配置、相同内层种子下的 12 对独立生成中有 11 对不同，平均绝对差约 0.409 个百分点。此差异反映该运行条件下的波动，不能仅靠现有样本分离服务时段、模型随机性等来源。
- 9 个 iStratDE 单元的赢家全部来自前四组；后四组反馈配置没有刷新最佳值。随机搜索的后四组也没有刷新任何单元的最佳值，固定配置仅一个单元后续改善。

所以，增加后四组搜索在这批数据中大多没有改变胜者。负的最终方法差值不能简单归咎于 DE 的反馈更新，因为 iStratDE 选中的程序都产生于反馈批次之前。

## 建议的下一步

**先进行两维、带重复运行的信号诊断，再决定是否继续研究 iStratDE。**

1. 后续开发实验只变化交叉概率与成绩权重，其他三维先固定在上述默认值。避免把大量试验分配给尚无有效作用机会的维度。
2. 对少量配置做独立重复，比较同配置波动与不同配置差异，并检查排序是否稳定。先冻结判断标准和预算，再申请新运行；本次没有启动它。
3. 若配置差异稳定，再让内层搜索和外层反馈各有更多发挥机会，并按相同候选预算与随机搜索比较。不能只扩大 iStratDE 一侧的预算。
4. 若仍不存在稳定信号，保留随机/固定配置作为实际方案，停止继续优化这个外层目标。若转而研究多样性或成本，应另立明确目标和协议。

任务是否适合继续研究，应根据训练/验证侧预先规定的饱和度与重复性标准筛选，不按测试集上哪项方法获胜挑任务。已经看过的最终测试结果不能继续用来调方案后又充当独立确认依据。
